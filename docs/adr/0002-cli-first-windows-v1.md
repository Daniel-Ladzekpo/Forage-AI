# Windows CLI first for v1

The riskiest part of Forage is turning arbitrary repositories into runnable Windows artifacts, not presentation, so v1 is a Windows-only CLI that proves the `describe → suggest → Package/Shortcut` loop end-to-end. A GUI or web service built now would defer the hard risk behind interface work; the Electron GUI, auto-updater, and cross-platform support were deliberately deferred to v2.

Status: accepted
